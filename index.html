About This Edition

The second edition of James Abela’s iGCSE Computer Science: Paper 2 has been updated for the 2029 curriculum, with Python at the heart of its practical approach.

Taking students from their first program to larger programming problems, this edition combines clear explanations, worked examples and challenges that encourage students to develop their own solutions. Topics include Python programming, computational thinking, flowcharts, searching and sorting, file handling, databases and SQL.

Build your skills through mini-projects and exam-style questions, using Python Code Lab to try out code and explore how it works. Dedicated chapters on testing, debugging and exam technique help you trace unfamiliar programs, explain your thinking and tackle scenario-based questions.

Whether used in the classroom or at home, this is a practical guide to writing, understanding and improving code.
